# Local Build Quickstart

This recipe builds the pinned OpenWrt target on a Linux development machine. It does not build or authorize a flashable SBG3300 image.

## Requirements

Install the host prerequisites required by the pinned OpenWrt release, including GNU make, gcc/g++, git, rsync, GNU awk, ncurses development files, flex, bison, bc, device-tree-compiler, Python 3 and standard archive/build tools. Keep target toolchain and staging generated by this checkout; do not borrow them from a different OpenWrt revision.

## Checkout and configure

```sh
export BUILD_ROOT="${BUILD_ROOT:-$HOME/sbg3300-build}"
export OPENWRT_DIR="$BUILD_ROOT/openwrt"
mkdir -p "$BUILD_ROOT"
git clone https://github.com/openwrt/openwrt.git "$OPENWRT_DIR"
git -C "$OPENWRT_DIR" checkout --detach 5edcc1c43cb97048b506168fbbe00538956796d6
test "$(git -C "$OPENWRT_DIR" rev-parse HEAD)" = 5edcc1c43cb97048b506168fbbe00538956796d6
grep -qx 'LINUX_VERSION-6.18 = .54' "$OPENWRT_DIR/target/linux/generic/kernel-6.18"
```

Copy the project target defconfig to `.config`, then run `make defconfig`. Confirm `CONFIG_TARGET_bmips=y` and `CONFIG_TARGET_bmips_bcm63268=y`. A device profile/DTS is research only; keep uncertain nodes disabled.

## Build with durable logs

Use a persistent process manager (tmux/systemd-run or detached nohup worker) and write the entire output to a path on persistent storage. Ensure only one make process uses the same checkout. Suggested command:

```sh
cd "$OPENWRT_DIR"
make -j2 V=s target/linux/compile > "$BUILD_ROOT/openwrt-6.18.54-build.log" 2>&1
rc=$?
printf '%s\n' "$rc" > "$BUILD_ROOT/openwrt-6.18.54-build.exit"
```

Record the start/end time, exact SHA, config hash, toolchain version and command in a manifest. Never infer success until exit code is zero and required output files exist.

## Validate

Check kernel directory `build_dir/target-mips_mips32_musl/linux-bmips_bcm63268/linux-6.18.54/`. Verify `.config`, `include/generated/utsrelease.h` says `6.18.54`, `Module.symvers`, `modules.order`, and `vmlinux`. Record artifact SHA256 and `file` output. Do not copy modules/images to the router.

For XTM external module work, follow `docs/LOCAL-DEVELOPMENT-HANDOFF.md` and require lawful external source, real implementations, full compiler/modpost logs, and an actual `.ko` before claiming static module success. Probe shims are not runtime-candidate code.
